CASTEP community documentation (castep-docs)
https://castep-docs.github.io/castep-docs/  ·  https://github.com/castep-docs/castep-docs

src/core/castep/keywords.generated.ts is generated by scripts/fetch-castep-keywords.mjs from the pages of
this documentation. It keeps only keyword and block names, types, defaults, allowed values and short
one-line descriptions, each attributed to the page it comes from.

The castep-docs repository does not state a licence (no LICENSE file; the GitHub licence field is empty),
so the copyright of the pages stays with their authors: the CASTEP developers and contributors listed on
the index page of the documentation, and for the phonon pages (Keyword-Reference.md) the Science and
Technology Facilities Council, Copyright (c) 2009 (Keith Refson).

CASTEP itself is distributed by its developers under its own licence (https://www.castep.org); no CASTEP
code or data is included here.

If the authors object to this use, or ask for different attribution, remove the descriptions with
`doc` entries from the generator and regenerate: names, types and allowed values are facts about the
input format, and everything else in DFTune's CASTEP support works without them.
